# V5：保存済み人物への性自認・性的指向の追加生成

承認された作業範囲は、保存済み8名に対する後付けの架空設定生成である。初回に未記載だった性自認・性的指向を推定して発見したとは扱わない。

## 確定条件

- 性自認と性的指向は別々の自由記述。分類の選択肢や人数比を設けず、特定のあり方を強制・除外しない。
- 未定や非開示という生成文もそのまま保存する。非開示から内部の正解を補完しない。
- 当人の元人格だけを参照させ、他7名の人格や追加生成結果を見せない。
- 元の氏名、年齢、16軸、経歴、自己紹介、判断原則は変更しない。
- 同名の人物はLeader ID・元人格SHA-256・元Evidence hashで区別する。
- 出生時の性別・身体情報・具体的な性的行為・国家設定・未来の展開は今回の追加対象にしない。

## 実行と保存

同じGeminiモデルのStandard設定で、1名につき1回、合計8回だけ生成する。各回の前に入力token数を確認する。入力上限16,000、生成上限2,048（thinkingを含む）、temperature 1.0、thinking LOW、候補1件、seed未指定。再試行・モデル変更・出力修復・再抽選はしない。料金と停止上限は実行前planに固定する。

通信・解析・形式検証・会計・記録のどこかで失敗した場合、元応答と停止記録を残して停止する。1名ずつ内容を確認してから次へ進む。確認は追加範囲と保存整合性だけを対象とし、性自認・性的指向の望ましさや多様性で選別しない。

各追加生成は新しいEvidenceRunに、入力、元応答、使用量、時刻、model version（返却された場合）、終了状態、hashを保存する。RAWとDERIVEDは分離する。元人格のEvidenceへ参照を持つが、元ファイルを変更しない。

追加設定はローカルの確認用記録とする。他国Agentへの自動公開や既存自己紹介への挿入は行わない。Simulation入力への接続、国家生成・割り当て、公開サイトへの掲載は今回の範囲外である。
