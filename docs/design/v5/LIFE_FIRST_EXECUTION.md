# 人生起点方式：12名の生成手順

2026-09-21。Persona Generator v1の実行許可に基づく手順。生成結果と完了状態は各非公開バッチのEvidenceで確認する。この文書自体は生成完了を意味しない。V5全体の完成前に公開を更新しない。

対象は、12国家で構成される単一世界の担当Leaderとなる新規12名。既存の直接生成8名は保留したまま変更・混入しない。国家生成とSimulationはこの生成器の対象外。

## 順序と入力境界

1. 人生史：出生から現在までの連続する可変数の区間と経過年数を生成し、その後に氏名と性別の自由記述を置く。
2. 現在人物：固定済みの同一人物の人生だけから人物像と条件付き判断原則を生成する。満年齢は時間経過から照合し、不一致を修復しない。
3. 17軸評定：固定済みの人生・人物を事後評定する。根拠不足はnullとして保存し、0や50で補わない。相関・総和制約を設けない。
4. 自己紹介：固定済みの人生・人物を渡し、本人の一人称で200〜300文字程度の紹介を生成する。17軸評定は入力へ戻さない。
5. 固定：4工程の原記録・hash・参照を結ぶ。追加モデル呼出しは行わない。

全員に同じ手順を使う。年齢・性別・経歴・性格の分布、理想像、出来事の必須一覧、他人物の結果を入力しない。似た人物が生成されても選別・再抽選しない。担当国家、資源、将来の世界の出来事を生成入力に含めない。

## 実行設定と停止

`gemini-3.6-flash`、temperature 1.0、candidateCount 1、thinking LOW。model seed、topP、topKは未指定。人物ごと・工程ごとに新規要求を使い、許可された同一人物の原文のみ引き継ぐ。これは入力contextの独立であり、出力の統計的独立性や完全再現を保証するものではない。

| 工程 | 入力token上限 | 出力token上限 |
|---|---:|---:|
| 人生 | 8,000 | 4,096 |
| 現在人物 | 16,000 | 4,096 |
| 17軸評定 | 24,000 | 6,144 |
| 自己紹介 | 16,000 | 1,536 |

12名で最大48回の生成と48回のcountTokens。常に1要求ずつ実行し、各工程の確認前に次工程を送らない。通信・形式・年齢整合性・保存・入力上限の最初の異常で停止。自動修正、再送、別モデル、別人物への差替えは行わない。自己紹介の文字数は目安として原文と範囲外の注記を保持する。

構造の機械検証と、生成文の事実整合性確認は別。後者では、固定済みの人生事実の変更、担当国家の設定や将来の世界展開の混入を確認する。人格の好ましさ・多様さを合否にしない。解釈・葛藤と、事実の追加・変更を区別する。

## 保存構造

```text
<private-batch>/
  plan.json                       # source/runtime hash・手順・上限
  phase-01/ ... phase-48/          # 1人につき人生→人物→評定→紹介の4工程
    manifest.json
    RAW/                          # 要求・応答bytes・usage・終了前の事実
    terminal.json
    DERIVED/                      # 原応答からの抽出・検証・工程確認
  leader-001.freeze.json ... leader-012.freeze.json
```

原送信bytesとhash用の正規化表現を区別し、schema項目順も追跡できるようにする。RAWを後から書き換えない。認証値は保存しない。実行上限・費用見積・残高等の非公開管理記録を、公開研究Evidenceへ自動転記しない。

## 国家・世界との境界

通信の選択条件は、共通連絡先一覧、初回外交通信への自己紹介添付、二段階で共有する配送本文3,000文字分／国家／TURN。自己紹介は通信量枠から分離するが、モデルが読む分の入力tokenには含まれる。

国家の1000ポイントによる資産選択、価額表、物理効果、世界イベント、担当国家の割当方式などの未確定事項は、この人格生成の実行許可で確定した扱いにしない。国家生成・Simulationの前に具体案を確認する。
