## 1. 地図と国家をどう記録するか

### G：共通地図

| 候補 | 具体的な生成内容 | 違い・限界 |
|---|---|---|
| **G-A：広さもAIが決める共通の平面地図案** | 一つのkm座標系、地図範囲、12国家の領域・海陸・地形をAIが生成。面積と幾何学的距離は同じ領域から計算。人口は後続の各国家生成で決める | 国家の広さを人間が配役しない。球面地球を精密再現するモデルではない。地図の大きさ自体も生成由来の条件になる |
| G-B：球面上の共通地図案 | 球面の半径・海陸・12領域を決め、球面距離と面積を使う | 全球の距離を扱える。半径を人間が固定するかAIに生成させるかを含めて選ぶ必要があり、幾何検査も増える |

G-Aを具体化の第一案とするが、まだ採用しない。人口・国土へ均一な値、望む分布、下限設備、各国の港、全国家の物流接続を強制しない。許容する物理範囲を後から結果に合わせて変えない。単に数値を扱えない場合は技術的な入力限界として区別する。

地図段階で領域を固定した後、国家生成にはその領域IDを渡す。国土面積や境界を再生成して二重の地図を作らない。位置や隣接から道路・港・船・同盟を自動付与しない。直線距離は実際の経路長や到着日数ではない。

競合領土の主張は幾何学エラーと区別して原文保存する。一方の主張だけで領土を移したり、矛盾を黙って丸めたりせず、未定義の構造なら停止する案。

### N：国家の記録と、生成時に見せる情報

**N-A案：自由記述と、照合可能な保有・地理を別の層にする。** 国家AIへは共通の地理情報、自国の領域、共通価格・能力仕様を渡す。他国の生成済みの社会・制度・資産選択は渡さない。APIの処理順で後続国だけが有利な情報を得ないようにする。

| 記録層 | 内容と境界 |
|---|---|
| 国家の識別・人口 | 固定の国家枠ID、AIが生成する国名・人口、地理枠の参照。国名の一致で別国を統合しない |
| 社会・経済・制度 | 自由な記述、強み・弱み、国内事情、技術的特徴。記述だけで未計上の設備・資源や数値効果を増やさない |
| 天然資源 | 賦存、採掘済み在庫、実際の利用能力を区別。地形や「資源が豊富」という文章から未計上の能力を付与しない |
| 所有資産 | 仕様ID、数量・単位、所在地、共用部分、稼働状態、必要入力、一覧外の原提案 |
| 保有ポイント | 取得評価額と別の残高欄。未価格の品目がある段階で、既知の小計から残額を確定しない |
| 対外関係 | 一方の認識・主張・希望と、双方が成立させた関係を別記録。片側の記述だけで他国の同意や条約成立にしない |
| 不明・来歴 | 不明値、入力・原応答、検証結果、価格表と地図の参照、版・hash。技術エラーを無行動や拒否に変換しない |

比較案N-Bは各国に自国の地理だけを渡す方式。周辺の地理条件が分からず、相互に整合した経路・設備を選びにくくなる。地図を生成AIへ渡す範囲と、SimulationのLeaderへ公開する範囲は別の決定である。

## 2. 初期資産の意味と計上

**A案：現に保有する物資・設備・利用能力を記録し、取得評価と稼働を分ける。** 国が初日から全て新築する前提にはしない。既存稼働・停止中・建設中を区別し、AIが生成した状態を残す。新品同等の評価を用いるか、劣化・進捗別に評価するかは価格仕様に明記する。資料のない一律割引は付けない。

| 共通の扱いとして提示する案 | 決めないまま実行しない部分 |
|---|---|
| 在庫は品目・品質・数量、設備は能力・必要入力・所在地まで特定 | 「食料」「医療力」「技術力」という名前だけに自由な物理効果を付けない |
| 税抜を識別できる取得費を基準とし、設置・配送・登録等は包含範囲を明記して部品と重複計上しない | 税抜への分解が不明な総額を一律補正しない。工事費と維持費の混在を純設備費と呼ばない |
| 既存・停止中・建設中も生成対象。状態別の評価と稼働条件を共通仕様へ置く | 既存設備を無料にせず、建設中を一律禁止しない。90日内に完成させる補正をしない |
| 計算は参照値と換算を正確に保持し、表示の丸めだけを分離 | 循環小数を切り捨てて予算内に見せない。現計算器へ分数換算を接続する準備は必要 |
| 一覧外は元提案を保持し、完全に同等の仕様なら共通単価へ対応 | 対応できなければ保存して停止。無料扱い・削除・類似品への強制置換・再抽選をしない |

同じ設備を大きくしただけで能力と価格が比例すると仮定しない。需要・燃料・作期・荷役・人員・水など、選択の意味に関わる条件は購入対象の仕様として国家生成前に提示する。必要量不明を0としたり、結果を見て設備を強化したりしない。

**残額の保有は採用済み。** 購入・交換・送金・利息等の具体的な利用ルールはまだ別工程であり、この資産計上案だけで発生させない。保有残高を消費させる指示も加えない。

### 価格・能力資料の到達点

| 分野 | 確認できたこと | 本生成の前に残ること |
|---|---|---|
| 備蓄・素材 | 2024年の6品目の参照価格 | 品質、保管、加工・栄養・用途の対応 |
| 発電 | PV・陸上風力の2024年設置費参照 | 具体設備・立地・入力・接続・稼働の条件。他電源を除外しない |
| 車両 | 同じ公表仕様の価格と積載量 | 燃料・運転・道路・積卸し・距離と配送時間 |
| 水処理 | 2024年契約額と処理能力の一次資料 | 契約に含む維持費等と取得費の分離。水源・電力・薬剤・人員 |
| 貯蔵・食料生産 | 2024年調査のサイロ見積、2024年水耕栽培の設備・運営試算 | 実測と試算を区別。穀種・水量・人員・作期等。不明な質量・栄養を補完しない |
| その他 | 通信・医療・道路・港・燃料供給・研究・行政・安全保障も対象から排除しない | まだ共通価格と能力が揃っていない。資産名だけの架空性能を採用しない |

## 3. 生成と配置の手順

**P案：共通地図を1回固定 → 同じ共通条件から12国家を別要求で生成 → 全原記録を保持して整合性確認 → 担当表を1つだけ作成。** 国家生成ごとに新しい要求を使い、先に生成した国の結果を次の国へ引き継がない。これは入力の独立であり、出力の統計的独立性を保証しない。

モデル設定の候補は、人生起点生成で使った `gemini-3.6-flash`、temperature 1、candidateCount 1、thinking LOW。国家・地図でも同設定を採用するかは未確定。model seed・topP・topKは人物工程では未指定だった。モデル設定と、下記の配置用seedは異なる。

入力文・schema・出力枠・token照合・保存確認・停止上限は、**生成する前**に固定する。最初の通信・schema・保存・整合性の異常で原記録を保持して停止する案。自動の再送・別国生成・出力修復・値の切下げをしない。失敗済み生成は成功世界と混ぜない。

### M：誰がどの国を担当するか

| 候補 | 固定する方法 | 偏りと注意点 |
|---|---|---|
| **M-A：事前固定した乱数で無作為配置する案** | 地図・国家生成前に配置用seed、アルゴリズム版、ID順を固定。人物IDを一度だけ並べ替え、固定順の国家枠へ割り当てる。実際の担当表は国家固定後に保存 | 内容を読んで適性合わせしない。偶然の偏りは保持。結果を見てseedを選び直さない |
| M-B：生成番号順に配置 | 人物001→国家001というID対応を生成前に固定 | 単純で再現しやすいが、人物・国家双方の生成順の偏りが重なる可能性がある |

一つの国家に一名を配置する意味であり、6組の会話ペアを作らない。12名全員を一度ずつ使い、対応表、使用ID一覧、seed、アルゴリズム・入力hashを保存する。固定済み人物が既に閲覧された事実と、国家がまだ未生成である時点も記録し、完全な事前盲検だったとは表現しない。配置用の乱数と順序を、外交名簿の表示・イベント・物理決済の優先順位へ流用しない。

人物の人生・自己紹介は原文保持する。その文章から担当国の地形・制度・資産を自動付与しない。人物記録と生成国に明白な事実衝突が生じた場合も、人物や国を都合よく書き換えず保存して停止する案。

## 実装・実行の境界

既にあるものは、固定済みの12人物、共通価格を受け取る純粋なポイント計算器、価格参照資料。地図・国家生成の実行schema、生成ランナー、地理・保有・能力の検査、残高のworld state接続は未実装。この一括案への確認を、未提示の価格・能力・実行上限への承認と広げない。

採用した設計を入力文・schemaへ具体化し、全12国家で同じ検証を通せること、出典と計算の固定、自由提案の扱い、入力の人物情報混入がないことをオフラインで確認してから、実行可能な状態を報告する。

### 呼出し数の見通し

地図1要求、国家1要求／国なら **地図・国家13生成要求**。担当表の作成はコードのみで追加APIなし。二段階判断を各TURNに1回ずつ置く場合のSimulationは **12名×2段階×3 TURN＝72生成要求**。残る生成要求は条件付きで85、完了済み人物48を含む全工程は133。token照会、再試行、World Eventや要約の別モデル呼出しはこの生成数に含まれない。これらの追加実行を認める意味ではない。

入力・出力token数と実行費用は、入力文・schema・出力枠が未固定なので未確定。過去の概算を今回の保証額とせず、具体的な実行枠は非公開の運用確認で扱う。

## 国家生成後、Simulation前に確定するもの

- 取得した資産の意味を変更しない範囲で、消費・生産・輸送・資源競合の時間発展と決済順を実装・固定する。
- World Eventの発生方式、通信・到着の時計、観測可能な情報、多国間の提案・同意・拒否・撤回・成立、ポイント利用を固定する。
- 人物のどの層を自身の判断入力へ渡すかと、相手へ見える情報、測定指標を区別する。17軸を他国へ公開しない。
- 生成された国の構成を見て、危機・協力・戦争・特定Leaderの活躍が出るようルールを調整しない。未定義で実行不能なら、その事実を残す。
- 3 TURNで停止。面白さ・平穏さを理由にターンを追加しない。V5完成前の公開更新は行わない。

## 今回まとめて確認する選択

第一案は **G-A（広さもAIが決める共通平面地図）＋N-A（共通地理を参照し、各国の結果は相互非公開で生成）＋A（取得評価と稼働を分ける資産計上案）＋P（保存・検証して異常時停止）＋M-A（生成前に方法を固定する無作為配置）**。

これらは新規提案であり、この資料作成を採用とはしない。違いを変更したい部分は記号単位で指定できる。個別価格・能力の未解決項目は採用済みにせず、生成前の準備として残す。
