# 単一世界の物理的な規模：国家生成前の確認

状態：現実の人口・日数・物量・距離を基準に設計する方式、および**1 TURN＝30日、3 TURN＝90日**に決定。**人口と国土の広さも国家生成AIが決める**方式を追加決定。人口・物量・地理の具体値や生成範囲は未決定。国家生成やSimulationはまだ行わない。[初期世界・資産の具体案](NATION_INITIALIZATION_REVIEW.md)に計上範囲と共通地理の選択を整理する。

12国家が同じ1つの世界に存在し、各国に1名のLeaderを置いて3 TURN観測する。国家はAIが生成する架空の国家であり、実在国を流用する方式へ変更しない。現実の単位を使うことだけでは、現実社会を精密に再現できたことにはならない。

## 時間の決定と比較経緯

| 候補 | 3 TURNの期間 | 観測上の違い |
|---|---:|---|
| 30日／TURN（採用） | 90日 | 備蓄消費、輸送、短期の応答を記録する。長期建設・研究は未完のまま終わり得る |
| 365日／TURN（比較のみ） | 1,095日 | 年単位の収支や設備の変化を含めやすいが、同じ判断機会の間に長い物理時間が経過する |

3 TURN、二段階判断、72判断要求という現在の規模は変えない。TURNへ出会い・危機・反応などの役割を割り当てない。365日は比較した固定日数案であり、暦年と同一ではない。

物理時間とLeaderの判断段階を区別する。二段階の判断をどの日に置くか、期間内の配送到着・在庫消費・稼働開始をどう記録するかを明示する。APIの応答順で国家を有利にせず、期間末への一括処理によって出来事の前後関係を変えない。物理時間を細かく処理することは、追加のLeader判断callを許可する意味ではない。

世界内の経過日数と、実際にAPIを実行したtimestampは別の欄に保存する。3 TURNで完成しなかった長期資産も、途中状態・投入・残る期間を保持する。

## 国家生成前にまとめて提示する初期世界の表

| 項目 | 決定する内容 | 避けること |
|---|---|---|
| 人口・面積 | 生成範囲、単位、需要と能力への関係 | 人口だけを無料の労働力とみなす、国家タイプを割り振る |
| 地理・距離 | 共通の位置から距離・経路を決める方法 | 各国が別々に相互矛盾する国境・距離を宣言する |
| 食料 | 物量、栄養換算、人口需要、損失・備蓄・供給 | 食料1トンを構成に関係なく同じ栄養量とする |
| エネルギー | 燃料・電力・変換・最終需要の境界 | 発電量と投入燃料を同時に使える在庫として二重計上する |
| 物流 | 積載量、便数、距離、経路容量、所要日数 | 輸送トン数とトンキロと日数を混同する |
| 初期資産の計上 | 土地・鉱床・設備・技術のうち1000ポイントへ何を含めるか | 自由記述で追加能力を無料付与する |
| 未使用ポイント | 許容するか、残額が何を意味するか | 無断で現金・将来の購入権へ変換する |

人口範囲・分布を、見た目の多様さや望む危機を作るために決めない。都市国家、大国などの配役を人間が与えない。同じ1000ポイントでも人口・地理・依存先による効果の差は残り得るため、同じ強さや生存率の保証とは扱わない。

## 単位・換算根拠の確認範囲

現段階では単位と勘定境界、参考基準が適用される範囲を確認する。具体的な資産・需要係数の採用後に、その能力値と適用条件を調べる。以下の資料があることを理由に、数値を自動採用しない。

- 食料：UNHCRの2,100 kcal／人／日は緊急食料援助の基準であり、全人口・全気候・全活動の普遍的な需要とはしない。[UNHCR Emergency food assistance standard](https://emergency.unhcr.org/emergency-assistance/food-security/emergency-food-assistance-standard)
- エネルギー：一次エネルギー、変換、最終需要を分ける。[IEA Understanding and using the Energy Balance](https://www.iea.org/commentaries/understanding-and-using-the-energy-balance)
- 物流：貨物量と輸送距離を組み合わせたトンキロを、設備の積載能力や配送日数と区別する。[UNECE Freight volume](https://w3.unece.org/SDG/en/Indicator?id=88)

共通ポイント価格は、実単位で定義した能力へ付けるシミュレーション内の設計上の価格であり、実市場価格の測定値ではない。一覧外の資産を共通能力へ対応させる方式は[資産評価の決定記録](NATION_ASSET_VALUATION_OPTIONS.md)に分離する。
