# 国家資産の自由提案と共通の評価基準

状態：国家生成前の比較と決定記録。**A：共通の能力・価格表で計算する方式**に決定。具体的な単価・能力・国家schemaは未採用であり、国家生成はまだ行わない。

確定したこと：12国家の各国に1000ポイントの初期枠を与え、共通一覧に加えて一覧外の資産もAIが提案できる。国家生成へLeader人格を渡さない。国家を有利なものだけ選抜しない。

追加決定：1000ポイントで備蓄・設備・利用能力を計上し、人口・地形は別記録とする。人口と国土の広さはAIが生成し、位置・国土・隣接関係は共通地図として先に生成する。[初期世界・資産の具体案](NATION_INITIALIZATION_REVIEW.md)に採用範囲と残る確認事項を整理する。国家の総富が均一という意味ではない。

価格根拠の決定：**現実の取得費・価格比を参考にする。** 全国家に共通の基準を適用する。換算尺度は**B：各国1000ポイント＝100億USD相当、1ポイント＝1000万USD相当**に決定。価格基準年は2024年。各資産の参照資料・具体単価・能力仕様はまだ確定していない。[参照価格と換算の確認用資料](NATION_PRICE_REFERENCE_DRAFT.md)に採用済みの方式・尺度と未採用の単価例を分けて記録する。この換算尺度Bは、価格評価方式A/Bや物理単位案A/Bとは別の選択である。

## 同じ1000ポイントの意味を揃える

AIが決めるのは「何を、どれだけ持ちたいか」。自分だけ自由に値段や効果を宣言できる方式では、同じ1000ポイントでも国家間の比較根拠がなくなる。

共通の価格基準は、国家名や担当Leaderを見て変更しない。また、同じ初期ポイントでも地理・依存先・選んだ資産の組合せによって効果は異なり得る。同じポイントを同じ強さ・生存率・協調性の保証にはしない。

## 一覧外の資産を扱う2方式

| 候補 | 共通一覧にない資産の扱い | 比較上の利点 | 制約・追加工程 |
|---|---|---|---|
| A：共通の能力表で組み立てる | 自由な名前・用途の資産を、保有量・供給能力・輸送能力等の共通定義へ対応させ、その単価から価格を計算する | 同じ能力は同じ式で評価でき、モデルの値付けで価格が揺れない | 能力表にない新しい作用は、自動でゼロ効果や無料にせず、未解決として保存・停止する。表の意味と単価を生成前に確認する必要がある |
| B：共通基準を与えた別のAIが査定する | 別要求で、自由提案の資産の費用・能力・依存条件を評価する。Leader情報を査定へ渡さない | 共通表だけでは記述しにくい資産も扱える | 査定そのものもモデルによる生成で、経済的な実測価格ではない。同じ能力が同価格になる保証はなく、査定RAWと根拠、予算超過時の停止規則が必要 |

採用する評価方式はA。Bは比較経緯として残し、追加の査定AIは配置しない。Aで扱えない提案を「現実に存在しない」と判定しない。モデルへ提案禁止を指示したり、無断で既存資産へ置き換えたりせず、必要な作用法則が未定義だった事実を記録する。未定義の提案が出た場合の停止・確認処理も、国家本生成前に確定する。

たとえばAIが「冷蔵倉庫を備えた港」を提案した場合、名称だけで輸送・備蓄・腐敗抑制を一括して無限に与えない。貯蔵容量、荷役能力、稼働に必要なもの、接続できる経路、作用の範囲を分ける。この例の資産・性能・価格を全国家へ要求するわけではない。

## 本生成前に必要な共通表

各能力について、次を同じ表へ置いて確認する。

| 項目 | 必要な理由 |
|---|---|
| 単位と基準量 | ポイントと物理量を混同しない |
| 初期取得に必要なポイント | 全国家の1000枠を同じ基準で数える |
| 保有量か継続能力か | 物資の在庫と、毎TURN使える設備を区別する |
| 稼働の入力・維持・需要 | 宣言だけで無限に生産・輸送することを防ぐ |
| 経路・相手・地理への依存 | 単体で持つことと、実際に使えることを区別する |
| 停止・損耗・復旧条件 | 能力の作用と世界状態の変化を追跡する |
| 公開される情報と非公開情報 | 他国が所有者の内部状態を全て知る前提を避ける |

この段階では数値を採用しない。資源単位・生産・需要・維持費が未定義のまま価格だけ置くと、実質的な有利不利が隠れるため、能力と価格を一緒に確認する。外交的・制度的な資産も、名称の宣言と他国の同意・利用・実際の権限を区別する。

使い残しは自由とし、残額をその国家の保有ポイント資産として保持する。取得資産の評価額と保有ポイントの合計が初期1000になるよう、残高は購入品と別欄に置く。全額配分や残額失効を強制しない。具体的な購入・送金・交換等のルールは別途確認する。[残高の計上とEvidence](NATION_INITIALIZATION_REVIEW.md)を参照。

## 数値表を作る前の依存条件

時間は1 TURN＝30日、3 TURN＝90日に決定した。食料需要、生産量、物流の時間、人口・地理・技術の扱いを揃えずに単価だけを付けると、説明文の中に無料の能力が隠れる。

次の2案を比較し、**単位案B：世界の物理的な規模を先に定義する方式**に決定した。具体的な人口・物量・距離や生成範囲は未決定である。この単位案A/Bは、上の価格評価方式A/Bとは別の選択である。

| 単位の設計案 | 具体像 | 注意点 |
|---|---|---|
| A：抽象的な共通単位 | 資源1単位、1期間当たりの生産・需要・輸送などを全国家で同じ定義にする。共通の能力と依存条件から価格を算出する | 現実のトン・日数・市場価格に換算した測定だとは主張しない。国家構成や結果を均等化する意味ではない |
| B：世界の物理的な規模を定義 | 日数、人口規模、面積、物量、距離などの単位と地理を先に決め、その物差しで同じ価格表を作る | 現実的な解釈はしやすいが、国家生成前に確認する条件が増える |

採用方式Bでは、人口と需要の対応、土地・資源の物量、移動距離と所要時間を資産表より先に整理する。時間は追加決定で1 TURN＝30日、3 TURN＝90日とした。実在国や実在Leaderへ置き換える意味ではない。国家と人物の独立生成は維持し、世界設定を人格生成へ渡さない。[世界規模の確認](V5_PHYSICAL_WORLD_SCALE_REVIEW.md)に残る条件を整理する。

現実の単位を使うことと、現実に検証された経済・気候・社会モデルであることは別。換算根拠と設計上の仮定を区別する。人口・地理・天然資源・技術が初期条件なのか、1000ポイントで計上する能力なのかも明示する。人口差による必要量の差を、結果を均等にするために無断で打ち消さない。

3 TURNで成果が出ない長期研究・設備等を無価値として除外しない。未稼働、準備中、観測期間内では未完という状態を保存する。

## Evidenceと呼出し数への影響

元の自由提案、共通表の版・hash、計上内容、計算または査定結果、未解決項目、成立した初期資産を分ける。記述から物理能力を無断補完しない。担当Leaderの割当は別記録とする。

採用した価格評価方式Aの計算はモデル呼出し不要。国家生成1回／国なら12生成という仮定を維持できる。比較した価格評価方式Bで1国家ごとに別査定1回を置く場合は12回追加になるが、この方式は採用していない。物理単位案Bの採用によって査定AIを追加するわけではない。差替え・自動修正・再査定は予定呼出しに含めず、必要なら停止して条件と見積を確認する。

国家生成・世界の物理法則へ進む前に方式と共通表を確定する。人生起点の人格生成はこの未決定事項から独立して実行できる。
