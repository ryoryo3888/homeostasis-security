# V5 — 単一世界の12国家・12名・3 TURN：設計変更と技術確認

2026-09-21。設計・オフライン確認のみ。新規モデル呼出し、国家・人格の本生成、Simulation、公開更新は行っていない。

## 1. 今回の確定構造

**12国家で構成される単一世界に12名の国家Leaderを1名ずつ配置し、その世界を3 TURN観測する。**

- world count = 1、run count = 1。1つのworld stateと共通の時間軸を持つ。
- nation count = 12、leader count = 12。担当国家割当表は12行で、各国1名を一つだけ保存する。交流相手の表ではない。
- 各国の初期資源総量は1000ポイント。AIがその枠内で資産を選ぶ既定方針を維持する。
- 12名全員を人生起点方式で新規生成し、全員を使用。年齢・性別・経歴・人格分布を割り当てず、選別・再抽選しない。
- 人生史 → 現在人物＋判断原則 → 17軸の後測定 → 本人の200〜300文字の自己紹介 → 固定・Evidence保存。
- 人格と担当国家の生成結果を互いの生成工程へ渡さない。内部人格値を他Leaderへ直接公開しない。
- 元の直接生成8名は予備記録として保留し、元入力・RAW・schema・追加設定を変更しない。大規模人格監査は実行計画に含めない。
- 世界全体が3 TURN進行した時点で必ず停止する。内容にかかわらず追加TURNや別runへ進めない。

12国家と12名を掛け合わせた組合せ実験ではない。別々の12世界でもない。潜在的な二国間関係66組と、有向関係132通りは、同じ世界内の関係候補数であってAPI要求数ではない。

各TURNへ外交・危機・反応等の役割を与えない。望む結末、出来事の順序、協調・戦争・リーダーシップ・創発をAgentへ命令しない。国家数変更を理由に、存在可能な現象や自由な要求を削減しない。

## 3. Leaderの担当国家割当

**既定資料には候補比較だけがあり、採用済みの具体的な対応アルゴリズムはない。** 各国を1名が担当する確定条件と、割当アルゴリズムが決まっていることを区別する。国家間の接触先はこの表から作らない。

候補は、生成前にseedとアルゴリズムを固定する無作為な1対1対応、または内容と無関係な事前IDによる決定的対応。対象ID・順序・必要なseed・実装版を結果を見る前に固定する。組合せは1つだけ保存し、結果を見て組み替えない。今回の確認ではどちらも無断採用していない。

[国家間交流の設計候補](V5_DYNAMIC_INTERACTION_PROPOSAL.md)でContact Selection、通信量、情報境界、多国間の扱いを比較する。固定ペアや専用仲介役を置かず、無制限の総当たり通信も採用しない。

## 4. 3 TURNでの停止と観測限界

TURNは世界全体の時間単位。12名が判断する度に世界を1 TURN進める実装にはしない。判断の同時性やTURN内の成立順序は世界法則として固定し、API呼出し順だけで物理的優先順位を決めない設計が必要。

3 TURNの状態を固定したら、到着待ちの輸送・同意待ち提案・未解決の出来事もその状態で保存する。後片付けのためのTURN 4や到着処理を追加しない。観測期間内の未到着を、将来も成立しないという結果にしない。長期観測は保存・固定後、別実験として設計する。

## 5. API呼出し量と見積の境界

| 工程 | 見積前提 | 生成call |
|---|---|---:|
| 新規12名の人生起点生成 | 1名につき4生成、固定処理はコード | 48 |
| 同じ世界に配置する12国家の生成 | 1国家につき1生成 | 12 |
| 単一世界の3 TURN観測 | 1世界、12 Leader、各TURN1回の判断 | 36 |
| 合計 | 最初の1 world・1 runまで | 96 |

上表は同時判断1回案の見積。新しい[交流方式の比較](V5_DYNAMIC_INTERACTION_PROPOSAL.md)で同TURN内の返答段階を加える場合はSimulation72生成、準備込み132生成になる。現在はS2（二段階）を軸に具体化する方針が確認された。通信量・公開範囲等の細部やAPI実行は未承認。

各生成前に1回token照会を行う場合は、96生成案では別に96照会、合計192 API要求。1回の判断に複数の発言・提案を含めることは可能であり、call数の仮定を行動数の制限にしない。

国家の共通地理・World Event・評価・要約などを追加LLMへ任せる方式は未確定で、この96生成には含まない。呼出し方式と実入力が未完成のため、正確なtoken量・完走費用は実測できていない。単価・仮定・通常費用・条件付き予約上限・停止上限案は非公開の費用資料で提示する。上限に収めるために情報や世界の可能性を無断で削らない。

## 6. Evidence構造への影響

人数に依存しない既存保存形式を使い、V5用の参照を追加する設計。元のEvidenceを移動・上書きしない。

```text
v5-single-world-experiment/
  design/                   # 生成前に固定した条件、方式、source hash
  personas/
    leader-001/ ... leader-012/
      life/ person/ assessment/ presentation/ freeze.json
  nations/
    nation-001/ ... nation-012/
  leader_nation_assignment.json  # 各国1名の担当割当。交流先とは別。親生成物のhashを参照
  world-001/
    initial-world.json      # 全12国家と唯一の対応表を参照
    run-001/
      manifest.json         # world_count=1、nation_count=12、leader_count=12
      RAW/                  # 全12名の入力・原応答、TURN 1〜3の共通世界/event
      terminal.json         # success/failure/interrupted、実際の完了TURN数
      DERIVED/              # 観測から計算した指標と原文への参照
```

1国家ごとに別世界・別runを作らない。Agentごとの記録も同じ`world_id`、`run_id`、`turn`を参照する。shared world stateと、各Agentが実際に見た入力の両方を保存して対応hashを結ぶ。全員が同じ情報を見たと仮定しない。

人格や国家の生成失敗も記録し、別人物・別国家で勝手に穴埋めしない。途中失敗では実際の完了TURN数を記録する。私的な開発相談・利用者等の実在の個人名・残高の会話は実験Evidenceへ含めない。AI生成した架空国家・架空Leaderの名称は観測対象として区別する。公開時期は従来どおりV5完成後の一括確認とする。

## 7. 今回の停止地点

単一世界の構造、必要変更、見積前提、Evidenceへの影響までを報告して停止。人格・国家の本生成、token照会、モデル試験、Simulation、追加世界、再組合せ、公開は実行しない。
