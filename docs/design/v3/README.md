## 設計で解決すべき主要な差

1. 既存7資源は0〜100の同型スコア。有限な物量と能力の区別が必要。
2. 既存6供給辺は多段連鎖をまだ作らない。伝播には明示的な投入依存と時間単位が必要。
3. 既存の条件は参加・自己要求量に対する契約で、相手の実現供給保証ではない。
4. 既存の原子的決済は部分配分した量の貸借を揃える。複数国の交換全脚成立契約とは異なる。
5. 既存Evaluatorは決済後だが復興更新前に呼ばれる。V3では正式TURN末snapshotを一つにする。
6. 既存research gateは80 calls／8TURNに特化し、全回答収束を審査理由にする。V3は技術完了と世界の結果を分けて設計する。既存gateは今回変更しない。
