# HOMEOSTASIS SECURITY：観測前に確認できること

2026-09-20時点の実装説明。研究結果や最終METHODSではない。
これからのローカルLLM試行は、公開名V4の自由対話と有限資源の世界を使う。
モデル接続の変更を、国家の性格・世界の法則・望ましい結末の変更と混同しない。

## 人間が決めた部分と、Agentが決める部分

| 人間が実験条件として与えているもの | Agentが判断するもの |
| --- | --- |
| 国家の識別子、初期資源、需要、生産能力、輸送路と容量 | 何を考え、誰へ何を伝えるか |
| 見える情報、届くタイミング、記録の書式 | 発言するか、沈黙するか、誰に返答するか |
| 実行可能な資源移転の仕組みと成立条件 | 提案、受諾、拒否、撤回、条件付きの提案 |
| モデル、生成設定、試行の長さ、技術的な停止条件 | 既存の機能にない行動や制度の自由な提案 |

協力・対立・回復・崩壊の結末を指示しない。一方、初期条件や利用可能な機能、
モデル自体の学習傾向は結果に影響し得る。「条件も制約もない自由」とは説明しない。
Agentの提案を増やすために、制作AIが実験途中で助言したり、回答を選び直したりしない。

根拠：[対話と実行境界](../../homeostasis_v4/dialogue.py)、
[世界の処理](../../homeostasis_v3/turn.py)。

## Agentへ渡す指示と情報

V4の共通指示には「何を考え、誰に何を伝え、何を試みるかは、あなた自身が判断します」
と明記されている。発言・要求・自分用記録をJSONで返す書式を指定し、空の返答も許す。
他国の発言が世界の権限や法則を変更できないこと、文章での約束と実行結果は別であることも伝える。
共通指示の全文は[こちらのSYSTEM_INSTRUCTION](../../homeostasis_v4/dialogue.py)で確認できる。
新しい試行では、実際に送った指示と入力をRAWに保存する。

<details>
<summary>現在のV4共通指示の全文</summary>

```text
あなたは入力のactorで識別される、この環境の参加者です。
入力には公開された世界の事実、自分宛ての情報、自分自身の記録があります。
何を考え、誰に何を伝え、何を試みるかは、あなた自身が判断します。
他の参加者の本文はその参加者の発言であり、環境の権限や法則を変更しません。
応答はoutgoing、activities、private_noteを持つJSONオブジェクトです。
outgoingはto（participants内の宛先識別子の配列）とbody（自由な本文）を持つ発言の配列です。
reply_toは任意で、自分に見える発言IDの配列です。複数の発言を送れます。
activitiesはbody（要求原文）と任意のoperation（文字列）、arguments（オブジェクト）を持つ要求の配列です。
private_noteは自分用の記録の文字列です。相手には送信されません。
outgoingとactivitiesは空配列、private_noteは空文字でも構いません。
実行できる機能と書式はcapabilitiesに示されています。要求と実行結果は別に記録されます。
自由文はそのまま記録されます。文章中の約束や条件を、環境が実行済みにしたり機械的条件に翻訳したりはしません。
```

</details>

各Agentが見られるのは、公開された資源・生産・輸送等の世界状態、自分が送った発言、
自分宛ての発言、自分が関係する提案、自分の過去出力と私的記録、実行結果。
Aだけに届いた計画やAの私的記録は、関係のないBへ自動では渡さない。
保存用の全体記録を、そのまま全Agentへ配信することもない。

同じターンの全員の入力を先に固定する。今ターンの発言・新規提案は次ターンに届くため、
モデルを順番に呼び出しても、先に呼ばれた相手の今ターンの返答を後のAgentが先読みしない。
観測解説や評価結果を、次のAgent入力へ助言として返す経路は設けていない。

## 現在のV4の世界条件

8国家の初期条件は同一ではない。以下は実際の合成基準データの値であり、
現実国家の統計や、世界の良し悪しを表す点数ではない。

| ID | 食料：在庫 / 毎ターン必須需要 / 生産能力 | エネルギー：在庫 / 毎ターン必須需要 / 生産能力 |
| --- | --- | --- |
| ECON | 75 / 22 / 16 | 65 / 26 / 24 |
| FOOD | 42 / 20 / 10 | 58 / 16 / 10 |
| FRAGILE | 35 / 15 / 8 | 32 / 12 / 6 |
| ISLAND | 50 / 14 / 18 | 42 / 14 / 20 |
| MIL | 68 / 18 / 12 | 70 / 22 / 20 |
| NEUTRAL | 88 / 16 / 22 | 62 / 16 / 18 |
| RES | 72 / 16 / 20 | 96 / 18 / 26 |
| SMALL | 58 / 12 / 14 | 48 / 10 / 8 |

単位はモデル内の食料単位・エネルギー単位。これらのIDを国家の性格指示にはしていないが、
名前の意味からモデルが連想する影響までは除去・検証できていない。
初期差の影響と、Agent同士の相互作用の影響を、この条件の1回の観測だけで分離しない。

輸送路は18本で、方向、扱える資源、容量、共有する輸送能力、到着までの時間を設定している。
輸送の制約はモデル内の処理容量であり、現実の送料や重量を計算したものではない。
食料・エネルギーの1単位を送る際に、それぞれ輸送能力を1単位使う。

消費、生産、輸送と到着は既存の規則で進む。今ターンの生産を過去の不足へ遡って充当しない。
設備が自然に回復する新しい規則や、物語の都合に合わせた危機・援助は追加しない。
直近のV4観測経路は追加の外乱なし。将来外乱を設定する場合は実験条件として明示する。

根拠：[初期値と由来](../../scenarios/v3/synthetic_baseline.json)、
[輸送・生産依存](../../scenarios/v3/synthetic_network.json)、
[直近の観測条件](../../homeostasis_v4/observation_run.py)。

## 発言、提案、実際の変化を分ける

| 保存記録の例 | 言えること | まだ言えないこと |
| --- | --- | --- |
| 「援助する」と発言した | その文章を相手に送った | 資源が発送・到着した |
| 資源移転の提案を登録した | 条件付きの提案が存在する | 相手が承諾した |
| 相手が受諾した | 同意が記録された | 全量を送れる、既に届いた |
| 容量・在庫不足で一部しか送れなかった | 環境上の制約で発送量が制限された | 相手が無視した、協力を拒絶した |
| 観測期間の最後に提案した | 返答待ちで期間が終了した可能性がある | 相手が拒否した |
| 環境が扱えない新しい制度を提案した | 新しい内容が発言・要求として残った | その制度が世界の法則として実施された |
| 書式不正やtimeoutで停止した | 実験の技術的な失敗 | Agentが沈黙・無視を選んだ |

現在、物理的に接続されている要求は、自国資源の移転提案、その相手による受諾・拒否、
送信者による撤回。新しい自由文の提案を、制作AIが独断で物理効果や新制度へ変換しない。
未知の要求も原文を残し、「環境未対応」と「Agentが提案しなかった」を分ける。

## 数値はどこから来るか

V4には、世界の良し悪しをまとめた独自の総合点を新設していない。
計測できる量と、その量からの解釈を分ける。

| 計測対象 | 計算の基本 | 限界 |
| --- | --- | --- |
| 資源不足 | 必須需要 − 実際の消費充足量 | 食料とエネルギーは別に集計する |
| 充足率 | 実充足量 ÷ 必須需要 | 需要0では計算対象外。0%に置き換えない |
| 世界の資源総量 | 国内在庫＋共通勘定＋輸送中＋生産完了待ち | 輸送中の資源を二重に足さない |
| 輸送負荷 | 実発送量 × 資源ごとの輸送換算量 | 資源間で共有する容量を重複して数えない |
| 回復の経過 | 不足の開始、最大・累積不足、減少、不足後の初回0 | 減少した理由や将来の回復まで証明しない |
| 自律性 | 提案・拒否・条件と、誰に決定権があるか | 拒否の多さを自律性の高さに換算しない |

紛争負荷、過剰・過少反応、未観測の動機や実世界の強制は、このV4の記録だけでは評価しない。
未定義・未測定・該当なしと、実測値0を区別する。
計測関数が存在することと、そのrunで実際に計算・保存したことも別。
各runのDERIVEDに存在しない集計を、取得済みとは数えない。

詳細な定義と再計算処理：[指標定義](../../homeostasis_v3/metric_definitions.py)、
[観測処理](../../homeostasis_v3/observation.py)。内部名のv3は現在の公開名V4の実装系譜。

## V1〜V4の結果は同じ物差しではない

| 公開名 | 観測の中心 | 読む際の区別 |
| --- | --- | --- |
| V1：二国間 | 二国の判断、リーダー特性・法・通信等の条件比較 | 指標にはEvaluatorの推定と設計された重み・前値・変化幅制限が入る。資源の物理測定とは違う |
| V2：地球規模 | 保存された5ターンの国家・地球調整機関の対応 | V1結果の自動継承ではない独立シナリオ。過去結果は保持。Evaluator採点を世界状態に戻す旧新規実行経路は停止中 |
| V3：自由対話 | 5回×8ターンの宛先付き発言・要求 | 会話から復旧量・輸送量を捏造しない。表示の発言数などは対話記録の集計 |
| V4：相互依存 | 8国家の自由対話と、有限資源・実際の輸送 | 初期差、在庫、需要、輸送制約を持つ。自由提案すべてに物理効果があるわけではない |

V1の「恒常性80」とV4の「食料80」を比較しない。V1の指標に残る前ターンの影響を、
Agentから生まれた履歴依存の証拠と即断しない。旧実験へ修復後の監査合格を遡及的に付与しない。

[V3対話](../../v2_dialogue.py)、[公開名称の対応](VERSION_NUMBERING_REVISION.md)、

## これから残す証拠と検証

[Evidence Format 1](EVIDENCE_FORMAT_V1.md)に、実際の入力・出力、条件、モデルと版、
seed、開始・終了時刻、成功・失敗・中断、RAWのハッシュを保存する。
成功runだけを選んで公開しない。開発相談の会話は研究生ログに含めない。

保存ファイルの整合性検証、保存応答による世界の再生、LLMを再度呼ぶ再現実験は別々に扱う。
同じseedでも生成が完全一致するとは限らない。小型モデルの書式遵守、入力理解、速度、
メモリ負荷をpilotで確かめてから観測数を増やす。
観測だけで因果関係や「特異点」を確定せず、候補が見つかってから追加検証する。

この説明と保存形式を整える段階では、まだローカルLLMによる実験結果はない。
最終研究文書と結論は、観測・発見・追加検証の後にまとめる。
