# V2の6指標を地球直下に置く限定改訂

Rioは「GLOBAL STATE｜地球全体の6指標」の画像と「V1 → 16条件・36回 → V2」の説明欄の画像を提示し、6指標をその説明欄の上へ置くよう指定した。画像の 85.0 / 79.0 / 80.0 / 77.0 / 78.0 / 17.0 は `v2_first_run.json` の第2ターンと一致する。対象は従来V2の1〜5ターン。

修正前の公開コミットは `79454caa2cd4b51137278dacadb611f1d9e1998f`。HTMLの元の順序は地球→6指標だったが、`homeostasis-research-layer.js` の `root()` が説明欄を地球直後に挿入し、6指標が説明欄の下へ押し下げられていた。

変更はV2の説明欄の挿入先を `.hero` の後から `#metrics` の後へ変える1か所だけ。結果は **地球 → 6指標の見出し・カード → 説明欄 → 指標推移**。既存のカードDOM、名称、数値、バー、表示ロジック、保存データ、CSS、地球には手を加えない。V1の配置分岐は不変。

正規の生成処理で共有スクリプトをV1/V2の公開HTML・プレビューへ同期するため、5ファイルに同じ1か所の差分が入る。V1では変更したV2分岐は動作せず、修正前後の全表示レコードが一致する。追加5回分の対話記録ページとV3には変更しない。

`tools/v2_metrics_position_revision.py` は指定の挿入先の1か所だけを逆変換し、従来の凍結ハッシュを維持する。`prove_source_delta` もこの改訂を明示的に照合する。基準ハッシュや過去の基準画像を新しい画面に合わせて書き換えることはない。

PC・iPadの修正前後12状態の差分は `v2-global-metrics-position-delta.json`。V1は完全一致、V2は全記録項目の文章・スタイル・横位置・幅・高さが一致し、地球を含む世界部分の縦位置も一致する。変化するのは、6指標と説明欄の縦位置のみ。

PC・iPad・スマートフォンの各5ターンで、見出し→6カード→説明欄の隣接関係、重なりがないこと、元JSONに一致する6数値とバーを `tools/check_v2_observation.py` で検証する。追加5回分の切替とV1/V2間の往復も引き続き確認する。

対象の単体テスト・全体の無料検証・公開後の数値と位置の確認を経て反映する。有料API実行や実験の再実行は行わない。
