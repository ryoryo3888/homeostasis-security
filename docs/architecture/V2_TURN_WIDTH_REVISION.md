# V2の5ターンカードを横幅いっぱいに並べる限定改訂

Rioの指示：2026-09-20「横いっぱいに広げて直そう！そのほうが早いし次に進める」。追加の有料実験ではなく、保存済み5ターンの表示幅だけを修正する。

変更前は `dc81c9b7fe5690a2c0696537374b087ae218f557`。`.rn-turns` の自動列数と全列をまたぐ疑似要素の見出しにより、カードが5枚でも6列目が残り、広い画面で右端に空きが生じていた。

V2のHTMLに限定した `v2TurnWidth` スタイルで、既存の5枚を折り返し可能なflex配置にする。見出しは1行全幅、カードは従来の最小幅205pxを基準に各行の残り幅を均等配分する。広い画面では5枚で全幅を使い、狭い画面では折り返した最終行も全幅になる。カード幅によって文章の折り返しと欄の高さ、その下の内容の位置は変わり得る。

カードDOM・内容・数値・クリック処理・元の5ターン記録・シミュレーションは変更しない。地球を含む上部の構造、色、文字の指定、アニメーション、他バージョンには変更を加えない。既存の生成処理はこのV2限定スタイルを保持し、公開HTMLとプレビューを同じ内容にする。

過去の基準ハッシュは更新しない。`tools/v2_turn_width_revision.py` は承認済みのスタイルブロック全体だけを逆変換する。`protected_bytes` と `prove_source_delta` で、この差分以外の変更を従来どおり拒否する。

修正前後のPC・iPadの12状態で文章・地球・操作欄・復旧欄の不変を比較し、幅の異なるローカル画面で右端まで埋まることと全5カードのターン切替を確認する。全体の `make check` とGitHubのCI成功後に公開する。有料API呼び出しは0回。
