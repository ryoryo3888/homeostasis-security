# V1・V2から追加5回分へ戻るための限定改訂

Rioから「V1 V2のページにはリンクボタンなくて、V2 5回分から先にとんだら…戻れない」と修正依頼を受けたため、バージョン切替だけを改訂する。

修正前の公開状態は `c20722662657e2f6d939809206c98948efed8028`。V1・従来V2の上部には2項目しかなく、追加5回分のページだけに3項目があった。

修正後はV1・従来V2の既存の `nav.version-switch` に `v2追加：5回分` のリンクを1つ追加する。狭い画面ではボタンを折り返す。リンク先は `results/v2-five-runs/index.html`。既存の現在地表示、親要素、リンク2項目は維持する。公開ページと生成プレビューの内容は一致させる。

`tools/navigation_revision.py` はこの2つの完全なHTML断片だけを許可する。従来の凍結ハッシュを更新せず、許可した断片を元に戻したうえで全バイトを照合する。誤った宛先・重複ナビゲーションは拒否し、地球などの無関係な変更は従来どおり検出する。コピー修正の証明にも、この限定的な追加を明示する。

変更関数：`original_navigation`、`add_return_link`、`protected_bytes`、`prove_source_delta`。ブラウザー検証は `follow_version_link` と `check` で、追加5回分 → V1 → 追加5回分 → 従来V2 → 追加5回分を実際のクリックで確認する。

PC・iPad・スマートフォンの修正前後の数値を `v2-return-navigation-delta.json` に記録する。地球の表現・寸法は不変。ボタンの折り返しによってヘッダーが自然に伸びる画面があるが、地球の親要素や世界の構成は変更しない。

対象テストと既存の全体検証を通したうえで公開し、公開URLでも同じ往復を確認する。実験ロジック、保存記録、V3、画像、Observerの動作、有料API呼び出しへの変更はない。
