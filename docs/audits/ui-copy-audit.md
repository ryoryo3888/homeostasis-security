# UI copy audit / Earth-first

対象は現行V1/V2、統合preview、Observatory、presentation、indexの転送入口、比較preview。過去のbefore/final/restored HTMLは履歴資料として変更しない。研究run、Agent原回答、計算式、表示値のbindingは不変。

| 文言の役割 | 判断 | 処置 |
|---|---|---|
| TURN、event、国家状態、Agentの判断、指標・資源・復興値 | 実データ | 保持 |
| 研究質問、次に未検証の問い | 作品の問い | 保持 |
| 単位、初期条件/AI判断/観測の区別、転換点の定義 | 研究上必要 | 保持。初期条件は地球表示後の開閉層へ |
| n=1、一般因果を断定しない、指標の限界、未達と条件参加の違い | 誤読防止 | 保持 |
| TURN、資源・条件選択、閉じる、Evidence、読込/エラー、キーボード操作 | 操作に必要 | 保持 |
| 10秒/30秒で理解、研究者向け、初見は簡単に | 閲覧者/速度の指定 | 削除。必要な内容見出しはAgent、TURN、Evidenceへ |
| 番号付き「読み方」、説明層を統合したことの説明 | UIの自己説明 | 削除 |
| 光の向こうに根拠、必要な深さまで、深く観測する | UI体験の宣伝 | 削除 |
| 「研究としての読み方」 | 内容は研究限界 | 見出しを「研究上の限界」へ。内容を保持 |

V1/V2の解説層が地球より前に挿入されていた順序を修正。地球・現在event・TURN操作の後に比較・解説・証拠を配置する。V2の初期被害と回復モデルの条件は削らず開閉層へ移動。V1の各指標は世界表示の後に保持。モバイルでは同じ世界パネルが国家パネルより先になる。

Observatoryは大見出しと体験説明を縮小し、実際の軌跡を先に置く。既存の選択・条件・移転・証拠の深度は維持する。地理データのないworldlineに新しい架空の地理・地球上の位置を付与しない。

生成元と埋込み版の不一致を防ぐため、preview生成は所有するCSS/JS層だけを毎回置換する。保護対象のUI hashは今回明示された変更範囲だけ更新し、変更前後hashを `ui-copy-audit.json` に記録。研究データと他の保護対象のhashは維持する。
