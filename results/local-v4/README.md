## 出力品質と限界

完了した第1ターンでは9通の発言と10件の行動要求を記録しました。
7件は`invalid_activity_request`（形式の不備5件、参照できない条件2件）、
3件は`environment_unsupported`でした。成立したofferと実行された行動要求は0件です。
発言を消したり、要求を書き直したり、成立したことにしていません。
行動要求が不成立でも、既存の世界ルールによる生産・消費などは別に進みます。

途中の第2ターンで返答した7国家は、JSONのキー順を除けば各自の第1ターンと同じ内容でした。
入力には前ターンの記録が含まれています。この反復の原因や、他モデルでも起こるかは未確認です。
書式が読めることだけでは状況・行動条件の理解を確認できず、今回は大量実行へ進める判定にはしていません。
時間枠だけを延長しても、この出力品質の問題が解消するとは言えません。

保存した応答から第1ターンの世界状態を再計算して一致を確認しました。
同じseedでモデルを再実行して同一の返答が出るか、長期安定性、創発・回復・協調の再現性は未検証です。
今回の停止は実行上の制限であり、Agentが対話を拒否したという結果ではありません。

## 照合方法

リポジトリ直下で以下を実行できます。モデルやAPIは呼びません。

```bash
python -B tools/verify_evidence.py results/local-v4/local-3630a0e5-68c9-4ea8-b17f-aa3a0c035585 --expected-evidence-hash ed43c801793f83af4223f067841e27c7bbbfcbf9610831ba32d932e891869314
python -B tools/run_v4_local.py --replay results/local-v4/local-3630a0e5-68c9-4ea8-b17f-aa3a0c035585
```

後者は`replayed_turns: 1`を返します。元のrunがfailureのため終了コードは1ですが、
整合性不一致による例外とは区別します。ハッシュ照合は内容の整合性確認であり、第三者によるモデル実行証明ではありません。

RAWとmanifest・terminalは取得時と全バイト一致する複製です。HTTP本文は`body_base64`に保存しています。
集計はRAWのハッシュを参照して分離しました。開発相談のチャット、APIキー、個人の絶対パスは含めていません。
研究手順全体は[Local pilot](../../docs/architecture/LOCAL_PILOT.md)、
証拠形式は[Evidence Format](../../docs/architecture/EVIDENCE_FORMAT_V1.md)を参照してください。
