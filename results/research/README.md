No new real research result has been produced in this task. Admission requires one complete eight-turn worldline, parsed schemas, country/coordinator/evaluator logs, 80 successful audited API calls, causal state continuity, derived events and state/action-dependent reconstruction. Complete response convergence requires review and is not automatically admitted. These are technical admission criteria, not evidence of a scientific conclusion.

Future readers should call `homeostasis_core.research_validation.accepted_research_paths(Path("results/research"))`. It verifies the result hash, acceptance manifest, transport audit and research requirements. Never glob debug, probe, rejected or legacy directories into this dataset.
