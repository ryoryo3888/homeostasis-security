05 / RESEARCH VS TECHNICAL VALIDATION

研究記録と技術検証を分ける

システムが正しく動くか確認するための技術テストと、研究結果として扱う実験は別々に保存しています。

FORMAL OBSERVATION

正式な研究観測

V1〜V4の研究目的に沿った世界、Agent、ターン、判断、world stateの保存記録です。

TECHNICAL VALIDATION

技術検証

V3のpreflight、V4のsdk-validationなど、実行経路や保存形式の確認です。正式な研究結論には自動集計していません。

LOCAL PILOT

ローカル試行

ローカル環境での小規模試行は、成立・失敗を含むengineering evidenceとして保持しています。Gemini観測と同一母集団には混ぜません。

06 / はじめてEvidenceを見る人へ

用語を短く説明します

RAW

加工前の生の実験記録。観測された入力・応答・状態です。

DERIVED

RAWから後で作成した一覧・分析・検証資料です。

run

同じ条件で世界を最初から最後まで動かした1回の実験です。

seed

乱数を生成する起点番号。同じ条件の世界を区別します。

TURN

シミュレーション内部の時間進行単位です。

SHA-256： 保存したデータが変わっていないかを確認するための識別値です。入口の見た目を変えても、保存済みEvidenceのSHA-256対応表は変更しません。
